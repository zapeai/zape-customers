OPTION 1: Local Development (Recommended)
────────────────────────────────────────────

  1. Install Docker Desktop:
     $ brew install --cask docker

  2. Install Supabase CLI:
     $ npm install -g supabase

  3. Start local Supabase:
     $ supabase start
     
     Copy the output keys!

  4. Create .env.local:
     $ cat > .env.local << 'EOF'
     NEXT_PUBLIC_SUPABASE_URL=http://localhost:54321
     NEXT_PUBLIC_SUPABASE_ANON_KEY=<paste_anon_key>
     SUPABASE_SERVICE_ROLE_KEY=<paste_service_role_key>
     EOF

  5. Run migrations locally:
     $ supabase db push

  6. Start Next.js:
     $ npm run dev

  7. Open Studio UI:
     $ open http://localhost:54323

  → See: LOCAL_DEVELOPMENT_SETUP.md


OPTION 2: Link to Production
────────────────────────────

  1. Install Supabase CLI:
     $ npm install -g supabase

  2. Link to production:
     $ supabase link --project-ref hegqofubmkhmwjvpssdi
     
     Enter your access token and DB password when prompted

  3. Push migrations:
     $ supabase db push

  → See: QUICK_START_SUPABASE_CLI.md


GITHUB ACTIONS SETUP (Required for Auto-Deploy)
────────────────────────────────────────────────

  Add these 3 secrets to GitHub:
  
  Settings → Secrets and variables → Actions → New repository secret

  1. SUPABASE_ACCESS_TOKEN
     - Generate at: https://supabase.com/dashboard/account/tokens
     - Click "Generate new token"
     - Name it "GitHub Actions"
     - Copy and save as secret

  2. SUPABASE_PROJECT_REF
     - Value: hegqofubmkhmwjvpssdi

  3. SUPABASE_DB_PASSWORD
     - From: Supabase Dashboard → Settings → Database
     - Database Password section

  Then test:
  $ git push origin main
  → Check GitHub Actions tab!
