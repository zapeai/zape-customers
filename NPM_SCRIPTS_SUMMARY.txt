 🎯 AVAILABLE NPM SCRIPTS
═══════════════════════════════════════════════════════════════════════

DEVELOPMENT:
  npm run dev                  → Start Next.js dev server
  npm run build                → Build for production
  npm run start                → Start production server
  npm run lint                 → Run linter

LOCAL SUPABASE:
  npm run db:start             → Start local Supabase (Docker)
  npm run db:stop              → Stop local Supabase
  npm run db:status            → Check Supabase status
  npm run db:reset             → Reset DB (re-run all migrations)

MIGRATIONS:
  npm run db:migration:new     → Create new migration
  npm run db:migration:list    → List all migrations
  npm run db:push              → Apply migrations
  npm run db:pull              → Pull remote schema
  npm run db:diff              → Diff local vs remote

PROJECT:
  npm run db:link              → Link to production
  npm run db:studio            → Open Studio UI
  npm run db:seed              → Run seed data

ADVANCED:
  npm run supabase             → Direct Supabase CLI access

 🚀 SUPER SIMPLE WORKFLOW
═══════════════════════════════════════════════════════════════════════

FIRST TIME SETUP:

  1. Install dependencies:
     $ npm install
     
     ✅ This installs Supabase CLI locally (no global install!)

  2. Start local development:
     $ npm run db:start
     
     ✅ First run downloads Docker images (~2-3 min)
     ✅ Subsequent runs are instant

  3. Apply migrations:
     $ npm run db:push

  4. Start Next.js:
     $ npm run dev

  Done! ✨

DAILY WORKFLOW:

  Morning:
    $ npm run db:start        # Start Supabase
    $ npm run dev             # Start Next.js

  Create Feature:
    $ npm run db:migration:new add_feature
    $ # Edit the SQL file
    $ npm run db:push
    $ npm run db:studio       # Check in UI

  Deploy:
    $ git add supabase/migrations/
    $ git commit -m "feat: add feature"
    $ git push origin main    # Auto-deploys!
